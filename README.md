# Smart Health

Site de demonstração do projeto Smart Health (Engenharia de Software I, ADS300, Univiçosa).

Mostra a fila e a espera das unidades de saúde de Viçosa, recomenda onde ir, tem mapa, comparação, acompanhamento de familiar e avisos. A área restrita tem o painel da unidade e o painel da gestão (alertas, demanda e picos, avisos e importação de histórico).

Todos os dados são de demonstração e ficam salvos só no navegador de quem abre.

## Como abrir

Abra o `index.html` no navegador. Não precisa instalar nada.

## Acesso de demonstração

- Unidade de saúde: senha `1234`
- Gestão municipal: senha `1234` e código de verificação `123456`
- Acompanhar familiar: código `SH-4821`
